# My Python Project Portfolio 🚀

Welcome to my central repository containing all the core Python desktop applications and tools I've built using PyCharm.

## 📂 Project Directory & File Guide

Below is a breakdown of what each file in this repository does:

*   **`currency_converter.py`**
    *   *Description:* A dynamic currency converter that fetches live global exchange rates from a secure API and tracks your calculation history with system timestamps.
*   **`guess_the_number.py`**
    *   *Description:* An interactive number-guessing game featuring dynamic difficulty levels (Easy, Medium, Hard) and a persistent local high-score logging engine.
*   **`password_generator.py`**
    *   *Description:* A cryptographically secure password generation tool utilizing Python's native `secrets` module to guarantee mandatory mixing of complex characters.
*   **`todo_list.py`**
    *   *Description:* A comprehensive task-management board equipped with a flat-style Dark Mode graphical user interface, task-priority sorting parameters, and local data caching.
*   **`weather_app.py`**
    *   *Description:* An advanced, multi-card digital weather dashboard showcasing 3-day extended regional projections and multi-row atmospheric telemetry.

---

## 🚀 How to Run the Applications

1. Clone this consolidated repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Open the directory within PyCharm.
3. Right-click any of the `.py` script files listed above and click **Run** to execute the dashboard or game instantly.
